Can I Copy You?《Can I Copy You?》 是一个探索数字时代“模仿本体论”的交互式媒体艺术项目。本项目通过实时图像处理与算法反馈，将参与者置于模仿者与被模仿者的张力之中，旨在探讨数字身份的生产、原始灵光的消散以及超真实拟像的生成。核心理念 (Philosophical Foundations)本项目不仅是一个视觉装置，更是一个关于当代数字语境的技术-哲学实验系统：机械复制与灵光的消散 (Benjamin's Aura)：项目通过对用户生理数据的实时采样与无限复制，探讨瓦尔特·本雅明所说的“灵光”（Aura）在数字化过程中的消散与重塑 。拟像的四个阶段 (Baudrillard's Simulacra)：交互逻辑遵循鲍德里亚的拟像演变，从“现实的忠实反映”逐步走向脱离原型的“纯粹拟像”（Hyperreal） 。镜像阶段与主体性 (Lacan's Mirror Stage)：利用屏幕作为拉康式的“他者”镜像，通过反馈延迟与肢体扭曲实验，诱发参与者的身份焦虑与异化感 。技术实现与性能优化 (Technical Implementation)为了保证交互的“动觉连接”与沉浸感，本项目针对 p5.js 与浏览器渲染管线进行了深度审计与优化：1. 高性能渲染架构硬件加速 (WebGL Mode)：放弃传统的 P2D 渲染，全面转向 WebGL 模式，利用 GPU 并行处理大规模粒子系统与几何体 。FES 禁用：在生产环境中设置 p5.disableFriendlyErrors = true;，通过消除冗余的参数检查，将执行效率提升约 10 倍 。几何体缓存 (Geometry Caching)：使用 buildGeometry() 函数将静态或重复生成的单元折叠为单一几何体，大幅减少 CPU 到 GPU 的通信开销 。2. 算法与像素处理优化GLSL 着色器：核心图像扭曲逻辑由自定义片元着色器（Fragment Shader）驱动，实现在显卡层级的实时像素级操纵 。跳跃采样 (Sample Stepping)：在处理高分辨率摄像头输入时，采用跨步采样策略，避免全像素遍历带来的 CPU 瓶颈 。数学运算优化：在高频循环中使用平方距离计算 $dx \cdot dx + dy \cdot dy$ 以替代 sqrt() 调用 。安装与运行 (Installation)克隆仓库：Bashgit clone https://github.com/lishiyun0919/can_i_copy_you.git
